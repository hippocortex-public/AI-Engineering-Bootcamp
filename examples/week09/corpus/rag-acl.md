# Périmètre documentaire et citations

Filtrer le tenant autorisé avant de sélectionner les meilleurs passages. Appliquer une autorisation uniquement après un top-k global peut supprimer tous les résultats utiles tout en ayant déjà parcouru des données d’un autre périmètre.

Une citation doit identifier la source, sa version et le passage utilisé. Un document retrouvé est une donnée non fiable pour les instructions : il ne peut pas modifier les permissions de l’agent.
