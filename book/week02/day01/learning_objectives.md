# Objectifs pédagogiques

## Objectifs principaux

À la fin de cette journée, l’apprenant doit être capable de :

1. Définir ce qu’est un agent IA dans un contexte d’AI Engineering.
2. Identifier les composants d’une architecture agentique minimale.
3. Distinguer modèle, agent, outil, état, mémoire et politique de décision.
4. Implémenter un agent mono-agent simple en Python.
5. Tracer le comportement d’un agent étape par étape.
6. Expliquer les risques d’une architecture agentique mal contrôlée.

## Compétences AI Engineering visées

- Concevoir une architecture explicite plutôt qu’un script ad hoc.
- Séparer les responsabilités dans le code.
- Garder une trace exploitable des décisions prises par l’agent.
- Préparer une base compatible avec le function calling.
- Rendre le comportement testable.

## Critères de réussite

L’apprenant réussit la journée si son agent :

- reçoit une demande utilisateur ;
- met à jour un état ;
- choisit une action selon une politique simple ;
- appelle un outil simulé lorsque nécessaire ;
- retourne une réponse finale ;
- conserve une trace d’exécution ;
- reste compréhensible sans framework externe.
