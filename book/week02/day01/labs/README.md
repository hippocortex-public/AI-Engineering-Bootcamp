# Lab — Architecture d’un agent

## Objectif

Implémenter un agent Python minimal pour comprendre les composants d’une architecture agentique.

## Fichier principal

```text
agent_architecture_lab.py
```

## Exécution

Depuis ce dossier :

```bash
python agent_architecture_lab.py
```

## Résultat attendu

Le script affiche :

- une réponse finale ;
- l’action sélectionnée ;
- la trace d’exécution ;
- le résultat de tests simples.
