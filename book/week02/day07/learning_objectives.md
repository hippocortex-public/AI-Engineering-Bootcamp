# Objectifs pédagogiques

## Objectif principal

Construire un **agent autonome mono-agent** capable de transformer un objectif utilisateur en plan d'action, d'exécuter ce plan via des outils et de produire une réponse finale sous contrôle.

## Objectifs détaillés

À la fin de la journée, l'apprenant saura :

1. expliquer ce qui distingue un agent autonome d'un simple appel LLM ;
2. concevoir une boucle agentique complète ;
3. représenter un objectif, un plan, des tâches et des observations ;
4. intégrer un registre d'outils ;
5. gérer les actions sensibles par approbation humaine ;
6. limiter une exécution par budget et nombre d'étapes ;
7. sérialiser l'état d'un agent pour audit ou reprise ;
8. écrire des tests de comportement agentique ;
9. identifier les risques liés à l'autonomie ;
10. préparer le passage vers les architectures multi-agents.

## Compétences AI Engineering

- modélisation d'état ;
- orchestration outillée ;
- stratégie d'arrêt ;
- garde-fous ;
- traçabilité ;
- testabilité ;
- design de boucle autonome ;
- séparation entre raisonnement, action et observation.

## Non-objectifs

Cette journée ne couvre pas encore :

- la coordination multi-agents ;
- MCP ;
- la mémoire vectorielle ;
- les files d'événements distribuées ;
- le déploiement production.
