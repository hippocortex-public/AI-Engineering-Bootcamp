# Références

## Références principales

- OpenAI Agents SDK — concepts d'agents, tools, handoffs, guardrails, sessions et orchestration.
- OpenAI Agents SDK — tools et function tools.
- OpenAI Agents SDK — tracing pour visualiser, déboguer et superviser les workflows.
- OpenAI Platform — Responses API et construction d'agents outillés.

## Concepts à retenir

- Un agent autonome doit être limité par des conditions d'arrêt.
- Les outils sont la surface d'action de l'agent.
- Les actions sensibles doivent être explicitement protégées.
- Les traces sont indispensables pour le debug et l'audit.
- L'état doit être sérialisable pour permettre reprise, audit et observabilité.
