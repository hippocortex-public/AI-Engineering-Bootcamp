# Lab — Agent autonome mono-agent

## Objectif

Exécuter un agent autonome contrôlé sans dépendance externe.

## Fichiers

- `autonomous_agent.py` : implémentation.
- `test_autonomous_agent.py` : tests déterministes.

## Exécution

```bash
python autonomous_agent.py
python test_autonomous_agent.py
```
