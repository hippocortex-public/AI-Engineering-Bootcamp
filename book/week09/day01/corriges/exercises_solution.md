# Corrigé des exercices

## Exercice 1

Indices de mots à partir de zéro : [0,4), [3,7), [6,10). Ne pas produire une quatrième fenêtre après la fin déjà couverte.

## Exercice 2

Une décomposition Unicode ou une suppression de caractères peut modifier les indices. Les offsets doivent pointer dans la source originale; la normalisation de recherche reste séparée.

## Exercice 3

Remplacer les chunks et leurs vecteurs, invalider les citations obsolètes et les mémoires dérivées de l’ancienne version. Recalculer les rapports si le corpus évalué change.
