## Concepts à retenir

- Le multi-agent est une décision d’architecture.
- Les patterns principaux sont manager-worker, handoff, router, parallèle et reviewer.
- Les contrats entre agents rendent le système testable.
- L’état partagé doit être minimal.
- Les traces sont indispensables.
- Le MCP sera traité plus tard dans la semaine.
