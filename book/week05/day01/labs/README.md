# Lab — Architecture production

## Objectif

Construire et valider un blueprint d’architecture production pour un système IA backend.

## Lancement

```bash
python book/week05/day01/labs/production_architecture_lab.py
python book/week05/day01/labs/test_production_architecture.py
```

## Ce que le lab démontre

- Définition de composants d’architecture.
- Validation des composants obligatoires.
- Validation des contrôles production.
- Détection des risques non documentés.
- Exigence d’approbation humaine pour actions sensibles.
- Versioning de prompts, schémas et modèles.
- Export JSON du blueprint.
- Export Mermaid de l’architecture.
