# Objectifs pédagogiques

## Objectifs principaux

À la fin de ce jour, l’apprenant doit être capable de :

1. Concevoir une architecture production pour une application IA backend.
2. Séparer API, service applicatif, runtime agentique, gateway modèle, gateway outils, état, mémoire, base métier et observabilité.
3. Identifier les risques de production spécifiques aux systèmes IA.
4. Définir des critères de readiness avant mise en production.
5. Formaliser un blueprint d’architecture validable par code.

## Compétences AI Engineering

- Architecture de systèmes IA.
- Design de frontières applicatives.
- Conception orientée fiabilité.
- Traçabilité des appels modèle et outils.
- Budget de latence et de coût.
- Séparation entre logique métier, orchestration agentique et infrastructure.
- Préparation au monitoring, à la sécurité et au déploiement.

## Ce qui doit être maîtrisé

L’apprenant doit savoir expliquer :

- pourquoi un appel direct au modèle n’est pas une architecture production ;
- pourquoi un agent autonome doit être contraint par un runtime ;
- pourquoi les outils sensibles doivent passer par des garde-fous ;
- pourquoi l’état conversationnel, la mémoire et la base métier ne doivent pas être confondus ;
- pourquoi les requêtes modèle doivent être traçables ;
- pourquoi les versions de prompts, schémas et modèles doivent être maîtrisées.
