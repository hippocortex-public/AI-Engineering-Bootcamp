# Lab — Architecture d'un mini-framework d'agents

## Objectif

Le lab formalise l'architecture du mini-framework sous forme de dataclasses Python et valide les invariants clés.

## Fichiers

```text
mini_framework_architecture.py
test_mini_framework_architecture.py
```

## Exécution

Depuis ce dossier :

```bash
python mini_framework_architecture.py
python test_mini_framework_architecture.py
```

## Concepts exercés

- composants d'architecture ;
- dépendances explicites ;
- détection de cycles ;
- décisions d'architecture ;
- rendu Mermaid ;
- sérialisation JSON ;
- tests d'invariants.
