# Lab — Workflow Engine

## Objectif

Implémenter et tester un moteur de workflow minimal pour le mini-framework d'agents.

## Fichiers

- `workflow_engine_lab.py` : scénario support IA et handlers métier.
- `test_workflow_engine.py` : tests unitaires sans dépendance externe.
- `mini_framework/workflow.py` : module réutilisable du mini-framework.

## Exécution

Depuis la racine du dépôt :

```bash
python book/week04/day05/labs/workflow_engine_lab.py
python book/week04/day05/labs/test_workflow_engine.py
```

Ou depuis le dossier du lab :

```bash
python workflow_engine_lab.py
python test_workflow_engine.py
```

## Attendu

Le script de démonstration affiche un `WorkflowRun` JSON.

Les tests doivent afficher :

```text
15 tests passed
```
