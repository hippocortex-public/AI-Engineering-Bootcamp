## À retenir

Les frameworks d'agents modernes distinguent de plus en plus :

- la définition d'agent ;
- l'exécution ;
- les outils ;
- la mémoire ;
- les garde-fous ;
- les workflows ;
- le tracing.

Le workflow engine du jour est une version pédagogique et déterministe de cette séparation.
