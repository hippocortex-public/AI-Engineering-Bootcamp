# Corrigé des exercices

## Exercice 1

p50 : rang plafond(0,5×4)=2, donc 200. p95 : rang plafond(0,95×4)=4, donc 1000. D’autres conventions interpolent : la méthode doit être écrite.

## Exercice 2

Sur 36 essais, le p95 est la 35e valeur triée. Le timeout est la 36e et reste visible dans le maximum et le taux d’erreur 1/36.

## Exercice 3

La grille attendue possède 36 paires uniques. Une observation absente rend la comparaison incomplète et peut cacher une erreur. Une étude acceptant une couverture partielle doit le définir explicitement, pas l’appliquer silencieusement.
